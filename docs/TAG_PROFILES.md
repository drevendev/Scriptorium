# Curated work tags · private source-free preview v1

Status: **executable offline extension**, issue #563. It does not classify literature automatically, publish a tag page, approve corpus rights, or reproduce FantLab. There are currently no admitted tag labels in the Reader; **no labels or public profiles are generated by default**.

## Generate a private profile

From a repository checkout with Python 3.13+, provide the existing source-free edition snapshot and an independently prepared curation file:

```console
scriptorium tags --snapshot scriptorium/data/evidence-snapshot.json --curation private-tags.json --output private-tag-profiles.json
```

For a **private, self-contained and printable HTML report** of the same confirmed curator-declared tags and five numeric metrics, run:

```console
scriptorium tags --snapshot scriptorium/data/evidence-snapshot.json --curation private-tags.json --format html --output private-tags.html
```

The HTML has **five metric-specific horizontal bar comparisons** across curator-declared tags, plus labelled numeric tables, observed/missing counts, exact units, honest zero-/one-work states, work hashes and curator evidence as inert text (no external links/scripts). A percent share uses a fixed 0–100% scale; other metrics use the highest observed tag mean **for that metric only** (or a clearly labelled 0–1 display domain for measured all-zero values). Each chart states its axis/domain and observed/missing counts; an unmeasured metric is **NOT_RUN and is not plotted as zero**. Decorative bars have accessible text/table equivalents and remain readable in print. Comparisons are descriptive, not independent confidence estimates or effect sizes. It is **not a public tag page or an independently verified permission**. JSON remains the default for machine-readable replay.

The tool will not download or ingest texts. The output destination is exclusive-create; it never overwrites a previous report. The HTML renderer also rejects tampered report metadata (aggregation method, source profile identity, schema), duplicate work identities, unsupported rights claims, non-HTTPS evidence URLs and unexpected source-bearing fields instead of silently presenting them as validated measurements. This checks internal consistency, **not** the truth of a curator's evidence or legal permission. It includes measured numeric scalars, work/source hashes and evidence URLs, but no manuscript text or word forms. The curation file must not be committed before independent rights and label review.

`private-tags.json` has this exact shape (field **names** only; not a real work/tag assertion):

```json
{
  "schema": "scriptorium-tag-curation-v1",
  "taxonomy_version": "editorial-taxonomy-v1",
  "tags": [{"id": "tag-id", "label": "Curator-provided display label"}],
  "editions": [{
    "key": "snapshot-book-key",
    "candidate_id": "snapshot-candidate-id",
    "edition_id": "snapshot-edition-id",
    "source_sha256": "64-lowercase-hex-characters-from-snapshot",
    "language": "ru",
    "translator": null,
    "rights": {"basis": "public_domain", "evidence_url": "https://source.example/rights", "reviewed": true},
    "annotations": [{"tag_id": "tag-id", "authority": "documented_source", "certainty": "confirmed", "evidence_url": "https://source.example/tag"}]
  }]
}
```

Example identifiers/URLs above are **placeholders**, not accepted source records. Supported rights assertions are `public_domain`, `open_license`, `explicit_permission`; assertions must be curator-reviewed. Labels may come from `human_curator` or `documented_source` with an HTTPS evidence link. `inferred` and `uncertain` annotations are accepted for audit but **excluded** from aggregate counts. The exact catalog layout forbids extra manuscript/text fields.

## Scientific and publication gates

Each selected edition must be present in the snapshot as `measured`, Russian-language, and at least **300,000 characters including spaces**, with identical candidate ID, edition ID, source SHA-256, language and translator. Duplicate sources, duplicated work identities and mixed metric profiles fail closed. The existing 29-field evidence snapshot is descriptive/diagnostic, not source-matched FantLab parity.

For each confirmed tag the report contains the exact sample size and source bindings, plus five fixed, unit-labeled metrics: mean word length, mean sentence length, dialogue share, comma rate and dash rate. Observed **per-book unweighted** mean, population standard deviation *between works*, min/max and missing count are emitted. A one-book tag has a null dispersion, a zero-book tag has null statistics, and absent metrics are **not** imputed to zero. These are descriptive distributions, not statistical confidence or author fingerprint scores. Reproducing a run requires the exact snapshot SHA-256 and taxonomy/edition evidence, recorded in the JSON output.

**Important:** source/rights/tag evidence is curator-*declared*, not independently authenticated by this command. `public_release_ready=false` and `rights_independently_verified=false` are unconditional. There is no publication switch. Real Reader tag filters/tables require separate audit of the complete source, explicit lawful reuse, independent tag evidence, verified frozen edition/translator identity, nonduplicate 300k+ works, reviewer acceptance and a separately implemented fail-closed publication renderer. The current 11 measured editions do not imply 11 tag-admitted editions. M2 remains **0/5**.
