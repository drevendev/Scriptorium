03 / HOW IT WORKS

No black box. No uploaded novel.

Scriptorium is an offline Python library and CLI. The full Reader generates a report for a local file, preserving its source identity without publishing its text. This Pages experience demonstrates the current verified measurements — it does not analyze arbitrary files in the browser.

01

Freeze the source.

Record edition, revision and SHA-256 before measuring. Different translations stay distinct.

02

Measure with units.

Calculate vocabulary, dialogue, sentence length and punctuation. Surface missing values explicitly.

03

Document the unknown.

Without FantLab’s analyzer input, exact rounding and backend, similarities remain diagnostics.
