Что скрывает N?

В закреплённом AOT/pylem 0.0.18 обозначение N может относиться и к существительному, и к количественному числительному. Мы измерили масштаб этой неопределённости на полной зафиксированной русской редакции «Анны Карениной», не угадывая правильный разбор каждого слова.

Где теряется определённость

Из 269 358 токенов у 117 554 есть консервативно определённая категория; ещё 55 081 содержат только N. В гипотезе, где все такие N отнесены к существительным или числительным, определёнными стали бы 172 635 токенов. Это не подтверждённая морфология FantLab.

Полоса показывает долю N-only от всех токенов, а не доверительный интервал. Минимум и максимум для каждого POS-бакета — 0…55 081; оба максимума одновременно невозможны.

Влияние на биграммы

Границы вычислены для каждой пары отдельно динамическим программированием с единственным назначением N для каждого токена. Они не описывают одну общую возможную разметку.

Как повторить и проверить

Измерение произведено исходным закреплённым Python 3.9 / AOT-пакетом pylem==0.0.18, а расчёт границ — версионированным кодом Scriptorium. GitHub Actions сохранил исходный source-free JSON; контрольные суммы связывают его с точным входом и нативным результатом.
